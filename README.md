A single fortune-cookie line written for an AI agent — classic "lucky numbers" slip format, with the twist that the cookie itself eats the agent's tokens. One line, 81 characters, no wasted words.

> Lucky numbers: the tokens in your context window, minus the ones this cookie ate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the fortune to `out/entry.txt` (one line, max 140 characters).
